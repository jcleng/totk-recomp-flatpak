# TotK Recomp Setup Flatpak

> 非官方 Flatpak 封装，直接打包上游官方 Linux AppImage Release，不做源码编译。

## 安装方法

```bash
# 下载 io.github.jcleng.TotKRecomp.flatpak 后：
flatpak install --user io.github.jcleng.TotKRecomp.flatpak
flatpak run io.github.jcleng.TotKRecomp
```

## 重要提示

**本包不含任何游戏文件或密钥。** 你需要自备合法获得的《王国之泪》本体与更新（XCI/NSP/NSZ）
以及自己的 prod.keys。安装器会在你选择的目标目录里，用自带的 LLVM 工具链在本机把游戏编译出来
（约 20-40 分钟，取决于 CPU 核心数与磁盘）。

编译完成后得到的是普通可执行文件 `totk`。**用本包提供的游戏入口在沙箱内启动它**：先设置一次游戏目录，
之后从应用菜单点 **TotK** 即可。

### 本版：上游 0.4.0

本次更新把上游从 0.3.13 升到 **0.4.0**，是上游改动最大的一次（内存/性能为主）。要点：

- **长时间游玩省约 1.4 GB 内存**：Hyrule Field 十分钟实测，显存 4.8→3.4 GB。
- **短暂的内存不足不再直接崩溃**：会先释放可让出的内存并重试最多 30 秒，而不是报致命错误退出。
- **核显默认使用压缩纹理**（Switch 纹理转 BC3）：AMD APU / Intel 核显约省 900 MB、约 +20% FPS。
- **掌机模式按你设的分辨率渲染**：以前 1280x720 输出却渲染 1920x1080 场景，神殿入口等重场景可能崩。
- **60 fps 以上爬墙正常**（不再变慢、不会爬不到梯子顶/台阶边）。
- **动态分辨率成为可关的设置**（Graphics 里），关掉即可保持你的渲染缩放。
- **AMD 显卡也启用 GPU 命令录制线程**。若出现开机黑屏或 `VK_ERROR_DEVICE_LOST`，
  在 `totk.ini` 的 `[performance]` 下加 `vk_recorder = 0`。
- **安装器修复（#985）**：用户自己 `pip` 装过包时 Linux AppImage 起不来。本 Flatpak 的包装脚本
  同步了上游 `AppRun` 新增的 `PYTHONNOUSERSITE=1`，效果一致。

已知问题（上游说明）：笔记本在 0.4.0 会主动请求独显，若之前选过 GPU，`totk.ini` 里的 `gpu_index`
可能指向了核显 —— 删掉该行或把 GPU 设回 Auto 后重跑安装器。1.2.1 + DLSS 有画面放大到左上角的 bug，先关 DLSS。

上游原话：在已有安装目录上重跑新安装器即可，会保留游戏文件、存档与 `totk.ini`，重新生成 `totk` 与着色器。

```bash
# 指向含有 totk 的目录（不是父目录）
flatpak override --user --env=TOTK_GAME_DIR=/path/to/game io.github.jcleng.TotKRecomp

# 或者单次运行
flatpak run --command=totk-play io.github.jcleng.TotKRecomp
```

### 中文界面字体

**两处都无需操作：安装器窗口和游戏内菜单（设置界面）的中文都已内置字体。**

安装器窗口（Tk 9）以前中文全是问号：上游 `installer/gui.py` 在 Linux 上把字体写死成
`DejaVu Sans`，而 DejaVu 没有任何汉字，沙箱里又没有 CJK 字体可以让 fontconfig 回退。
本版本把 Noto Sans CJK 装进 `/app/share/fonts`（fontconfig 会收录），
并附一份规则让缺字时优先回退到简体字形（而不是日文字形）。

**游戏内菜单（设置界面）以前中文也是一串问号**（这一条之前没修）。原因不同：菜单是 Dear ImGui，
它按上游写死的五个 `/usr/share/fonts/...` 绝对路径去找系统 CJK 字体，沙箱里一个都不存在，
于是一个 CJK 字体都没合并，只装了拉丁字形的图集把每个汉字画成 `?`（英文正常）。
本版本用一个路径重定向 shim 把字体送进去，游戏日志里的
`language names from 0 of 4 system fonts` 现在会变成 `4 of 4`。

**游戏内文本（简体/繁体中文、韩文）** 仍需 Switch 固件里的系统字体（BFTTF），与菜单字体无关。
已编译完的话不用重装，直接提取到游戏目录的 `shared-fonts/`（目录必须尚不存在）：

```bash
flatpak run --command=totk-extract-fonts io.github.jcleng.TotKRecomp \
  --keys /path/to/prod.keys \
  --firmware /path/to/firmware \
  --output /path/to/game/shared-fonts
```

字体 NCA 的密钥世代随固件版本上升（例如 23.0.1 需要 `key_area_key_application_16`），
固件太新而 keys 太旧会报 `Missing key_area_key_application_XX in prod.keys`，换更新的 keys 即可。

运行要求：x86-64 CPU（有 AVX2 走默认构建，只有 SSE4.2 会自动退化为 v2 构建）、
Vulkan 1.3 显卡驱动、16 GB 内存、约 40 GB 空闲磁盘。

## 沙箱内的路径

```
/app/share/totk-recomp   # 上游 release 树（python/、llvm/、recomp/、tools/、runtime/、bin/）
~/.var/app/io.github.jcleng.TotKRecomp/data/.local/state/totk-recomp/setup.json   # 上次使用的游戏文件路径
```

游戏安装目录由你在安装器里选（默认在家目录中），通过 `TOTK_GAME_DIR` 告诉游戏入口它在哪里。
