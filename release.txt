# TotK Recomp Setup Flatpak

> 非官方 Flatpak 封装，直接打包上游官方 Linux AppImage Release，不做源码编译。

## 安装方法

```bash
# 下载 io.github.jcleng.TotKRecomp.flatpak 后：
flatpak install --user io.github.jcleng.TotKRecomp.flatpak
flatpak run io.github.jcleng.TotKRecomp
```

## 重要提示

**本包不含任何游戏文件或密钥。** 你需要自备合法获得的《王国之泪》本体与更新（XCI/NSP/NSZ）
以及自己的 prod.keys。安装器会在你选择的目标目录里，用自带的 LLVM 工具链在本机把游戏编译出来
（约 20-40 分钟，取决于 CPU 核心数与磁盘）。

编译完成后得到的是普通可执行文件 `totk`。**用本包提供的游戏入口在沙箱内启动它**：先设置一次游戏目录，
之后从应用菜单点 **TotK** 即可。

```bash
# 指向含有 totk 的目录（不是父目录）
flatpak override --user --env=TOTK_GAME_DIR=/path/to/game io.github.jcleng.TotKRecomp

# 或者单次运行
flatpak run --command=totk-play io.github.jcleng.TotKRecomp
```

### 中文/韩文界面字体

中文/韩文/繁体界面文字需要 Switch 固件里的系统字体（BFTTF）。已编译完的话不用重装，
直接提取到游戏目录的 `shared-fonts/`（目录必须尚不存在）：

```bash
flatpak run --command=totk-extract-fonts io.github.jcleng.TotKRecomp \
  --keys /path/to/prod.keys \
  --firmware /path/to/firmware \
  --output /path/to/game/shared-fonts
```

字体 NCA 的密钥世代随固件版本上升（例如 23.0.1 需要 `key_area_key_application_16`），
固件太新而 keys 太旧会报 `Missing key_area_key_application_XX in prod.keys`，换更新的 keys 即可。

运行要求：x86-64 CPU（有 AVX2 走默认构建，只有 SSE4.2 会自动退化为 v2 构建）、
Vulkan 1.3 显卡驱动、16 GB 内存、约 40 GB 空闲磁盘。

| 构建来源 | 上游官方 `TotK-Setup-x86_64-0.3.13-linux.AppImage` |

## 沙箱内的路径

```
/app/share/totk-recomp   # 上游 release 树（python/、llvm/、recomp/、tools/、runtime/、bin/）
~/.var/app/io.github.jcleng.TotKRecomp/data/.local/state/totk-recomp/setup.json   # 上次使用的游戏文件路径
```

游戏安装目录由你在安装器里选（默认在家目录中），通过 `TOTK_GAME_DIR` 告诉游戏入口它在哪里。
